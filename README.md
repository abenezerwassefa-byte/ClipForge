# ClipForge
A local Python-based media automation tool that combines voice recordings, background music, and video with AI-generated, timestamped captions to produce polished MP4 videos. Powered by OpenAI Whisper for local speech transcription.

IMPORT LIBRARIES

LOAD WHISPER
TRANSCRIBE VIDEO
EXTRACT SEGMENTS

LOAD VIDEO
LOAD VOICE

TRY:

    GENERATE CAPTION CLIPS

    COMBINE ORIGINAL AUDIO + VOICE

    COMBINE VIDEO + CAPTIONS

    ATTACH MIXED AUDIO

    EXPORT VIDEO

FINALLY:

    CLOSE FINAL VIDEO
    CLOSE ORIGINAL VIDEO
    CLOSE VOICE
